# v0.7.4 · Editorial 2.0 管理台、独立签到与 PR #66 加固

本版把 PR #66 的方向落地为六章节管理台：自动签到成为独立章节，模型路由与选号积分下限各自拥有明确的保存状态。管理台、OAuth 回调页与产品页统一为 Editorial 2.0 单色排版。

## 主要变化

- **六章节控制台**：概览与监控 / 账号池与授权 / 自动签到 / 客户端接入 / 模型与路由 / 用量与明细。签到章节包含四种模式、整批错开、失败重试、出口回落与最近 48 小时审计。
- **有方向的模型路由**：按「源区域 + 源模型 → 目标区域 + 目标模型」配置。路由只在逻辑请求入口匹配一次；同源站/源模型的多条规则形成有序备用链，仅在目标无账号或当前模型冷却时推进。
- **独立选号门槛**：`GET` / `POST /direct-admin/api/quota-floor` 与独立保存按钮；低额度账号是硬排除，不进入全冷却兜底。
- **配置状态清晰**：签到、路由、积分下限分别显示加载、未保存、保存中、已保存及失败状态；轮询不会覆盖正在编辑的草稿，保存失败保留输入。
- **产品页 Issue No. 07**：8 项能力、6 个客户端示例、7 平台二进制与 Docker；全部使用本地系统字体，不请求外部资源。
- **PR #66 后续修复纳入**：并发快照兼容、`.env` 换行转义、管理台主 API Key 越权、环境变量/Admin API/CHANGELOG 文档。

## 回归修复

- 递归重试不再对已路由模型重复套用规则。
- 低于积分下限的账号不会因缺少未来重置时间或全冷却兜底而重新被选中。
- 自动及手动 token refresh 恢复国际站 OAuth 专用出口选择。
- 签到失败重试按北京时间当日 23:30 截止；在此之前，失败日志仍能继续推导重试。
- Responses 直连 SSE 恢复 keep-alive；仅带转发头的隧道场景要求关闭连接。
- 模型目录恢复 60 秒 TTL 与 `fresh=1` 绕过负缓存。
- Windows 权限测试与 48h 日志边界测试不再产生平台/时钟误报。

## 升级注意

- 旧路由表中缺少 `fromSite` 的规则不会匹配；升级后请在「模型与路由」章节重新保存。
- `X-Site` 请求头不是硬钉；只有模型名 `cn:` / `global:` 前缀会跳过路由。
- 签到配置、模型路由、积分下限分别保存，不会互相夹带修改。
- 自动签到默认关闭；新增开关与默认值见 `.env.example`、`docs/guides/configuration.md`。
- Docker 用户使用 `ghcr.io/wnddd839/buddy-proxy:v0.7.4` 或 `latest`；更新前保留数据卷。
