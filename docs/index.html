01 /
Capabilities

一件事做到位.

不是多厂商聚合，也不是代理池转发。这个项目只做一件事：把 CodeBuddy 账号转为标准 OpenAI 兼容接口。

协议直连架构

PROT-01

默认 protocol_direct。OAuth 授权完成后直接向 CodeBuddy 上游通讯，不再挂起本地 codebuddy --serve 进程，也不依赖任何外部浏览器扩展或 Cookie 嗅探插件。

标准 OpenAI 形状

SPEC-02

完整支持 GET /v1/models、GET /v1/model/info 与 POST /v1/chat/completions。流式与非流式调用双向兼容，轻松对接入 NewAPI、Cursor、Claude Code 与 OpenCode。

智能号池与自动熔断自愈

POOL-03

号池按区域隔离轮询。上游 429 时将该账号冷却 2 分钟（111xx 为 5 分钟，部分 5xx 为 30 秒），冷却期内不参与轮询；同区全冷却时选最早恢复者继续服务，避免整体不可用。

直读官网真实 Credits

CRED-04

管理控制台直接对接官方用量接口，实时拉取并展示「剩余 / 总额」真实数值。剩余额度一目了然，绝无虚标伪造状态。

国内与国际双区精准调度

ROUT-05

请求调度端点严格以账号自身注册区域为基准，不依赖反代宿主机的出口 IP，确保国内凭证走腾讯云通道，国际凭证直达海外节点。

Token 计量与 Reasoning 思考链

THNK-06

流式响应收尾补发真实 usage chunk 与缓存命中度统计；原生透传 reasoning_effort 思考档位参数，完整支持 Claude 3.7 Thinking 与 DeepSeek R1 思考过程输出。

04 /

          
Getting Started

          
三步跑起来.

        


        

          

            
01 /

            
运行二进制程序

            
从 Releases 下载对应架构的文件，双击或在终端启动。程序自动读取同目录配置并打印出专属 API Key。

          

          

            
02 /

            
进入控制台完成 OAuth

            
在浏览器打开 http://127.0.0.1:32126/direct-admin/，点击「开始认证」一键完成微信/企微或海外授权，账号自动入池。

          

          

            
03 /

            
配置下游工具使用

            
在你的编程助手（如 Cursor、Claude Code、OpenCode）中填入 Base URL http://127.0.0.1:32126/v1 与 API Key 即可。
