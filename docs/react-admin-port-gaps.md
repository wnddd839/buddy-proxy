## 8. 收尾前必修清单（按优先级）

### P0 —— 不修就不能叫「移植完成」

1. **概览页/导航恢复「静默失效命中」可见性**（§1.7）
   旧版把命中数放在首屏，是因为这个功能的意义就是「不让人漏看」。现在必须点进
   「静默体检」才看得到，且导航项没有 badge。
   建议：在 `OverviewPage.tsx` 顶部加一枚指向 `tab-invariants` 的命中/未启用徽标
   （命中 > 0 用 `--err`/`--warn`），并在 `AppShell.tsx:118–122` 的 nav item 上加
   `badge`（复用 `attentionCount` 同款写法）。
   **判定标准**：从任意页刷新后，不点「静默体检」也能看出「过去 24h 有没有命中」。

### P1 —— 信息缺失，会让运维做出错误判断

2. **标题改写补三句口径**（§5.5–5.7）：fail-closed 识别条件、只改模型名不动
   `messages/stream/max_tokens/header`、删除 `reasoning_effort`/`reasoning`。
   这三句在旧版是「敢不敢开」的依据，不是装饰文案。
3. **事件表「大小」列改回「system 长度」并补 UTF-8 字节 tooltip**（§3.9）。
   否则读者会把 `1.2 KB` 读成字符数或 token 数，而同一页的剥离统计是字节。

### P2 —— 轻微，但都是一类「静默退化」

   命中列表容器一个稳定锚点。
